# 주식노트 (StockNote)

서버 없이 **내 폰에만 저장되는** 주식 보조 앱입니다. 아이폰 홈 화면에 추가해서 일반 앱처럼 쓰는 PWA(웹앱)이며, 한 번 열고 나면 인터넷 없이도 동작합니다.

## 기능

| 탭 | 내용 |
|---|---|
| **보유** | 매매 기록으로 보유수량·평균단가(이동평균법)·평가손익·수익률·비중·실현손익 자동 계산. 원화/달러 분리 집계 |
| **일지** | 매수·매도 기록과 매매 이유 메모, 월별 정리, 실현손익·승률·이번 달 손익 |
| **계산기** | 물타기/불타기 평단(최대 5차 분할), 목표 평단 역산(몇 주 사야 하는지), 수수료·세금 반영 목표 수익률별 매도가 |
| **관심** | 목표가·손절가와 현재가 거리(%), 도달 표시 |
| **차트** | 캔들/라인 + 이동평균(5·20·60) + 볼린저밴드 + 거래량 + RSI(14) + MACD(12,26,9), 골든/데드크로스 표시, 기술적 종합 점수, 지지·저항·손절 참고 가격대, 최근 신호 목록 |

- **주식과 ETF**를 구분해 기록합니다. 국내 ETF는 매도 거래세를 면제하고, 배당·분배금도 기록합니다(세후 집계).
- **실시세 연동 (무료 API, 서버 없음)**: 설정 → 데이터 연결에 키를 넣으면 앱이 각 서비스에 직접 요청합니다.

  | 데이터 | 서비스 | 비고 |
  |---|---|---|
  | 국내 주식·ETF 일별 시세, 종목 검색 | 공공데이터포털 (금융위원회 주식시세정보 / 증권상품시세정보) | 전 영업일 종가 기준 |
  | 해외 주식·ETF 시세·일봉, 종목 검색 | Twelve Data | 무료: 분당 8회, 하루 800회 |
  | 해외 종목·시장 뉴스 | Finnhub | |
  | 국내 공시(DART)·국내 뉴스 | 바로가기 링크 | 무료 API가 브라우저 직접 요청(CORS)을 막음 |

  앱을 열 때 30분이 지났으면 자동으로 시세를 업데이트합니다. 키는 기기에만 저장되고 백업에 포함되지 않습니다.
- 키가 없어도 현재가·시세를 **직접 입력**하거나 엑셀·증권사 화면의 표/CSV를 붙여넣을 수 있어요.
- 데이터는 기기(브라우저 저장소)에만 저장됩니다. **설정 → 백업 파일 저장**으로 주기적으로 백업하세요.
- 기술적 분석은 참고용이며 투자 판단의 책임은 본인에게 있습니다.

## 아이폰에 설치하기

1. 이 폴더를 정적 호스팅에 올립니다. 가장 쉬운 방법은 **GitHub Pages**:
   저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   브랜치(예: `main` 또는 작업 브랜치)와 `/ (root)` 선택 후 Save.
   잠시 뒤 `https://<계정>.github.io/<저장소>/` 주소가 생깁니다.
   (비공개 저장소의 Pages는 유료 플랜이 필요합니다.)
2. 아이폰 **Safari**로 그 주소를 엽니다.
3. 공유 버튼 → **홈 화면에 추가**.
4. 홈 화면의 *주식노트* 아이콘으로 실행하면 주소창 없는 앱 화면으로 열립니다.

> 호스팅은 앱 파일을 한 번 내려받는 용도일 뿐이고, 내 데이터는 서버로 전송되지 않습니다.

## 개발

외부 라이브러리·빌드 과정 없이 순수 HTML/CSS/JS입니다.

```
index.html            화면 뼈대
style.css             스타일 (라이트/다크 자동)
js/app.js             상태·화면·계산 로직
js/indicators.js      이동평균/볼린저/RSI/MACD/신호 분석
js/chart.js           캔버스 차트
js/data.js            무료 API 연동 (공공데이터포털, Twelve Data, Finnhub)
sw.js                 오프라인 캐시 (Service Worker)
manifest.webmanifest  PWA 설정
icons/                앱 아이콘
tests/                단위 테스트, iPhone 화면 스모크 테스트
```

```bash
npm start          # http://localhost:8080 에서 실행
npm test           # 지표 계산 단위 테스트
npm run test:ui    # Playwright로 iPhone 화면 흐름 테스트
```

앱 파일을 수정하면 `sw.js`의 `CACHE` 버전(`stocknote-v1` → `v2` …)을 올려야 설치된 앱에 새 버전이 반영됩니다.
